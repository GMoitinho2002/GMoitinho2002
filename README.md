## 🚀 Projetos em destaque

### ✅ [TaskFlow](https://github.com/GMoitinho2002/taskflow)

Sistema Full Stack para gerenciamento de tarefas, desenvolvido com **ASP.NET Core, Angular e Entity Framework Core**.

Principais recursos:

* Cadastro e gerenciamento de tarefas
* Controle de prioridade e status
* Interface desenvolvida com Angular
* API REST documentada com Swagger

### 🚚 [Vehicle Control API](https://github.com/GMoitinho2002/vehicle-control-api)

API REST inspirada em cenários reais de logística e rastreamento, desenvolvida com **C# e ASP.NET Core**.

Principais recursos:

* Cadastro e gerenciamento de veículos
* Registro de posições
* Consulta de histórico por período
* Identificação de veículos sem comunicação

### 🎫 [HelpDesk API](https://github.com/GMoitinho2002/helpdesk-api)

API REST para abertura e acompanhamento de chamados técnicos.

Principais recursos:

* Abertura de chamados
* Controle de prioridade e status
* Atribuição de responsáveis
* Comentários e histórico de atendimento
* Resumo de chamados por status
